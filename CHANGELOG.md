# Changelog

## 0.1.0 — initial curated baseline
- Added engineering charter, architecture and contribution standards.
- Added security, privacy, accessibility, performance and reliability standards.
- Added lifecycle, incident response and reuse-first closeout workflows.
- Added risk-based quality gates.
- Added beginner-to-advanced competency roadmap and curated learning resources.
- Added intake, ADR, threat-model and closeout templates.
- Curated references from MDN, W3C, OWASP, NIST, Google, AWS, OpenTelemetry, React, TypeScript, PostgreSQL and Playwright.
