# Website Development Ecosystem

A reusable playbook and learning system for planning, designing, building, testing, securing, shipping, operating, and improving websites and web applications.

## Start here
1. Read standards/ENGINEERING-CHARTER.md.
2. Follow workflows/PROJECT-LIFECYCLE.md for each project.
3. Complete templates/PROJECT-INTAKE.md.
4. Select a quality profile in quality/QUALITY-GATES.md.
5. Follow learning/ROADMAP.md and learning/COURSE-CATALOGUE.md.
6. Complete workflows/PROJECT-CLOSEOUT.md at project close.

## Repository map
- standards/: engineering, architecture, security, privacy, accessibility, performance.
- workflows/: project lifecycle, contribution, incident response, reuse-first closeout.
- learning/: beginner-to-advanced competency roadmap and curated courses.
- quality/: risk-based testing and release gates.
- templates/: intake, ADR, threat model, PR, closeout.
- catalogue/: reusable asset register.

## Default lifecycle
Discover → define → design → architect → plan → implement → review → test → secure → release → observe → improve → close out and contribute reusable assets.

## Principles
User needs and evidence first. Accessible, private and secure by design. Small reviewable changes. Reproducible builds. Test user-visible behavior. Measure performance on real devices. Backups and rollback are part of production readiness. Reuse proven assets. Document provenance, licensing, compatibility and test status. Treat AI-generated code as untrusted until reviewed and tested.

This is a flexible playbook, not a mandatory stack. Preserve a project's sound existing architecture unless evidence justifies change.
