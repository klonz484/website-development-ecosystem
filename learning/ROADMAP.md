# Web Engineering Roadmap: Beginner to Expert Practice

This is competency-based, not a promise that a fixed number of hours creates expertise. Advance when you can build, explain, debug, test and improve independently.

## Level 0 — digital and developer foundations
Learn files/folders, browser devtools, editor, terminal, HTTP, URLs, DNS, client/server and Git. Build and publish a static page. Exit: explain request/response and use Git branch/commit/push.

## Level 1 — web foundations
Learn semantic HTML, forms, CSS cascade/box model/Flexbox/Grid, responsive design, JavaScript, DOM, events and accessibility. Build an accessible responsive multi-page site. Exit: works on phone and keyboard without a framework.

## Level 2 — frontend developer
Learn modern JavaScript, modules, async/await, fetch, browser storage, TypeScript, components, routing, state, forms, API integration and design systems. Build a typed API-driven dashboard. Exit: test key logic and user journeys; explain component boundaries and state ownership.

## Level 3 — full-stack developer
Learn server runtime, HTTP/API design, SQL, schema design, authentication, authorization, sessions, validation, migrations, uploads and background jobs. Build a full-stack app with real database, roles and deployment. Exit: explain request path and trust boundaries.

## Level 4 — production engineer
Learn CI/CD, environments, secrets, logging, metrics, tracing, caching, queues, backups, recovery, security tests, performance budgets and incident response. Build a production-like app with automated pipeline and monitoring. Exit: deploy safely, diagnose failure and restore data.

## Level 5 — senior engineer
Learn maintainability, refactoring, code review, domain modelling, API evolution, distributed systems, reliability, threat modelling, cost management, mentoring and technical writing. Evolve a system over multiple releases. Exit: lead design review and mentor others.

## Level 6 — staff/principal/architect practice
Learn system design, organizational architecture, platform engineering, developer experience, governance, resilience, vendor risk and technical strategy. Build a multi-team architecture proposal and migration plan. Exit: improve outcomes across teams without overengineering.

## Specializations
Backend/platform, cloud, security, data, mobile/PWA, design systems, accessibility, performance, AI integration, e-commerce, content/SEO and analytics.

## Practice loop
Learn → build → test → explain → review → refactor → document. Expertise requires deliberate practice, debugging, code review, production ownership and learning from failures.
