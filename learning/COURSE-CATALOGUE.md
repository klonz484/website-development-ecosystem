# Curated Course and Resource Catalogue

A curated sequence from beginner to advanced. Many resources are free; optional paid material may exist. Verify current availability and terms with each provider. Course completion is not proof of expertise.

## Beginner
1. MDN Learn Web Development — https://developer.mozilla.org/en-US/docs/Learn_web_development — structured learning from setup through core frontend skills.
2. MDN Curriculum — https://developer.mozilla.org/en-US/curriculum/ — essential competency map.
3. The Odin Project — https://www.theodinproject.com/ — free, project-based foundations and full-stack path.
4. freeCodeCamp — https://www.freecodecamp.org/learn/ — interactive exercises and project certifications.
5. web.dev Learn — https://web.dev/learn/ — HTML, CSS, JavaScript, accessibility and performance.

## Intermediate frontend
6. JavaScript.info — https://javascript.info/ — JavaScript and browser tutorials.
7. React Learn — https://react.dev/learn — official React learning path.
8. TypeScript Handbook — https://www.typescriptlang.org/docs/handbook/ — official TypeScript guide.
9. Full Stack Open — https://fullstackopen.com/en/ — University of Helsinki course covering React, Node, APIs, testing and modern full-stack topics; best after basic programming.
10. Vite Guide — https://vite.dev/guide/ — frontend tooling and build workflow.

## Backend and data
11. Node.js Learn — https://nodejs.org/en/learn — official Node learning resources.
12. PostgreSQL Tutorial — https://www.postgresql.org/docs/current/tutorial.html — SQL and relational database basics.
13. Supabase Docs — https://supabase.com/docs — Postgres, authentication, storage and Row Level Security.
14. MDN HTTP — https://developer.mozilla.org/en-US/docs/Web/HTTP — protocol, caching, cookies and security.

## Advanced and production
15. OWASP Developer Guide — https://devguide.owasp.org/ and ASVS — https://asvs.owasp.org/ — secure application requirements and verification.
16. NIST SSDF — https://csrc.nist.gov/projects/ssdf — secure development lifecycle practices.
17. Google SRE Books — https://sre.google/books/ — reliability, monitoring and incident response.
18. DORA capabilities — https://cloud.google.com/architecture/devops — software delivery and organizational capabilities.
19. AWS Well-Architected — https://docs.aws.amazon.com/wellarchitected/latest/framework/welcome.html — operations, security, reliability, performance, cost and sustainability.
20. OpenTelemetry — https://opentelemetry.io/docs/ — traces, metrics and logs.
21. Playwright Best Practices — https://playwright.dev/docs/best-practices — resilient browser testing.
22. WCAG 2.2 — https://www.w3.org/TR/WCAG22/ — normative accessibility standard.

## Suggested sequence
MDN Getting Started/Core → Odin Foundations → JavaScript.info → React and TypeScript → Full Stack Open → Node/PostgreSQL → testing and CI/CD → OWASP/NIST → SRE/DORA/Well-Architected → specialization projects.

Pick one primary course at a time. Build projects yourself. Do not skip HTML, CSS, JavaScript, HTTP, SQL, Git, accessibility or testing to rush into frameworks. Recheck links periodically; this is a curated list, not an endorsement of paid offerings.
