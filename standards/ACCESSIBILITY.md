# Accessibility Standard

Default target: WCAG 2.2 Level AA. Automated scans alone cannot prove conformance.

## Design and implementation
Use semantic HTML and native controls first. Ensure keyboard access, visible focus, logical focus order and no traps. Provide labels, instructions and accessible errors/status messages. Maintain text and non-text contrast; never rely on color alone. Support zoom and reflow. Give meaningful images alternatives. Caption meaningful video and provide transcripts where appropriate. Respect reduced motion. Make touch targets usable. Use descriptive headings, landmarks, link names and page titles. Test dialogs, menus, forms, validation, authentication and dynamic updates.

## Verification
Combine automated checks such as axe with keyboard-only testing, screen-reader sampling, zoom/reflow, contrast checks and task-based testing with disabled users where feasible. Record gaps and owners.
