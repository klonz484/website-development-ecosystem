# UI library changelog

## 0.1.0 — initial component library
- Added semantic light/dark design tokens.
- Added buttons, labelled form controls, checkbox, switch and radio group.
- Added native modal dialog, responsive navigation and semantic data table.
- Added dashboard cards, statistic cards and page header.
- Added accessible component tests and adoption guidance.

## 0.1.1 — accessibility and release hardening (in review)
- Connected checkbox and switch help descriptions to their controls for assistive technology.
- Fully disabled non-essential spinner and switch motion when reduced motion is requested.
- Added a release-grade manual accessibility test matrix and axe-based consumer testing guidance.
- Added reproducible npm lockfile generation and a CI workflow that commits the lockfile from trusted same-repository pull requests.
- Added npm OIDC trusted-publishing workflow and first-publication runbook; initial npm scope ownership and bootstrap publication remain maintainer actions.
