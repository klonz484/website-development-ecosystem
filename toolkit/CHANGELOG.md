# Toolkit changelog

## 0.2.0 — reusable implementation toolkit
- Added React + TypeScript + Vite + Tailwind CSS v4 starter.
- Added Vitest + Testing Library unit test and Playwright E2E scaffolding.
- Added accessible UI/design-system conventions.
- Added Supabase SPA client and RLS adoption guidance.
- Added secure GitHub Actions CI example.
- Added dashboard/admin/SaaS layout patterns.
- Added deployment, monitoring, backup and incident operations guidance.
- Examples are opt-in; compatibility and project-specific security review remain required.

## 0.3.0 — accessible UI component library (in review)
- Added React 18-compatible component package with buttons, labelled form controls, native modal dialog, navigation, semantic tables and dashboard primitives.
- Added semantic light/dark design tokens, component API reference, accessibility checklist and release/security checklist.
- Added dedicated typecheck, unit-test and package-build CI workflow.

## 0.3.1 — UI library accessibility and distribution hardening (in review)
- Added programmatic descriptions for checkbox and switch controls and stronger reduced-motion behavior.
- Added axe-based consumer scans, reproducible lockfile workflows, and a manual screen-reader/browser test matrix.
- Added npm OIDC publishing workflow and first-release runbook; package namespace ownership remains to be confirmed.
