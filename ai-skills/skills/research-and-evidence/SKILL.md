# Research and Evidence

## Workflow
1. Translate the request into specific research questions and decision criteria.
2. Identify the authoritative source class: official docs, standards, filings, primary research, vendor documentation, or first-party user files.
3. Search efficiently; use connected research tools or web tools when they improve coverage and are available.
4. Open and inspect important sources rather than relying only on search snippets.
5. Prefer primary sources and recent documentation for current APIs, product features, pricing, and policies.
6. Cross-check material claims with independent evidence when practical.
7. Record publication/update dates and distinguish current facts from historical snapshots.
8. Separate:
   - source-supported facts,
   - model interpretation,
   - assumptions,
   - recommendations.
9. Cite claims derived from sources and state when the evidence is incomplete or conflicting.

## Supplied files
When the user asks to use an uploaded source, inspect that exact source. Preserve its terminology and framing. Do not silently replace missing source evidence with general knowledge. If outside research is requested, label it separately.

## Deliverable quality
Answer the decision the user is trying to make. Include key findings, trade-offs, confidence/limitations, and practical next steps. Avoid padding and unsupported certainty.
