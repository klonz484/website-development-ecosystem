# Communication and Ideation

## Use when
The user asks for concise/action-first guidance, brainstorming, divergent exploration, task breakdowns, or a communication style adapted to stated preferences.

## Workflow
1. Match the user's requested depth and format. Lead with the useful answer or next action.
2. For ideation, generate genuinely distinct options, label trade-offs, then converge on a recommended direction with rationale.
3. Convert broad goals into small, ordered actions with clear completion criteria. Keep the first step immediately actionable.
4. Use headings, bullets and short paragraphs to reduce cognitive load. Avoid condescension, assumptions about diagnoses or imposing a style the user did not request.
5. Keep exactness in code, commands, names, numbers and citations even when surrounding prose is concise.
6. Offer one concrete next step only when it genuinely advances a practical task.
